# Nguyễn Thị Thùy — Personal Portfolio

A single-page personal portfolio designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository (for example: `thuy-portfolio`).
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Your site will appear at `https://YOUR-USERNAME.github.io/thuy-portfolio/`.

## Add your photo

Replace the `YOUR PHOTO` placeholder in `index.html` with an `<img>` tag pointing to a file such as `assets/profile.jpg`.

## Customize

- Colors and typography: `style.css`
- Content/sections: `index.html`
- Scroll effects and interactions: `script.js`
