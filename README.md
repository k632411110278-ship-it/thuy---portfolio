# Nguyễn Thị Thủy — Personal Portfolio

A visual, editorial-style personal portfolio for GitHub Pages.

## Structure
- `index.html` — main page
- `style.css` — layout, typography, responsive design
- `script.js` — scroll progress, mobile navigation and reveal animation
- `assets/` — personal and portfolio images

## GitHub Pages
Upload the contents of this folder to the root of the repository, then set:
- Branch: `main`
- Folder: `/ (root)`
